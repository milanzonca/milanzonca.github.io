# milanzonca.org

Source code for my personal academic website, published at
[milanzonca.org](https://milanzonca.org).

The site is built with [Hugo](https://github.com/gohugoio/hugo) and hosted on
[GitHub Pages](https://docs.github.com/en/pages). It presents my research,
publications, and related academic materials.

## Built from a template

This website is built on Pascal Michaillat's
[minimalist Hugo template for academic websites](https://github.com/pmichaillat/hugo-website)
(documented at [pascalmichaillat.org/b](https://pascalmichaillat.org/b/)), which
itself adapts the [PaperMod theme](https://github.com/adityatelange/hugo-PaperMod).
The template has been customized here for my own content and needs. Full credit
for the underlying design goes to those projects.

## Content

- `content/` — pages and publications (Markdown, with associated PDFs and images)
- `config.yml` — site configuration
- `layouts/`, `assets/` — template customizations layered over the theme
- `themes/PaperMod/` — the base theme
